# Projects

Independent projects belong in `<short>/`, one lowercase hyphenated folder per real project, with a `README.md` as its entry point. Client-owned work can stay under `clients/<short>/projects/` in a client workspace.

Use the Project README format in `.agents/skills/personal-memory/supporting-templates.md`. It links the goal, completion check, files, tasks and authoritative memory without duplicating their contents. Choose useful project subfolders during setup; do not inherit ticket folders for non-client work.

Read `memory/preferences/document-scaffolding.md` for the selected layout. This folder is intentionally empty of project records until there is real work to organize.
