## Active memory

- Applies when the owner asks about a website, portal or web app, or when a task stalls behind a web sign-in.
- Status: not yet approved. Ask once, in one line: "Want me to open the browser so you can sign in and we can look at <site> together?"
- When the owner says yes: overwrite the Status line with `Approved YYYY-MM-DD: open the browser without asking` and commit. From then on, open it straight away and say which site and what you are checking.
- A no applies to that request only; the next web question asks again.
- The browser is a visible one the agent can drive and that keeps the owner's logins. The owner does every sign-in and MFA prompt; the agent never types credentials.
- In the browser the agent reads and navigates only. Any change on the site (submit, save, delete, send) is named and confirmed first.
