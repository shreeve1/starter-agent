## Active memory

Applies to research files agents write (`research/`, and ticket or project research files where a skill keeps them), and to what a subagent returns for them.

- Each Findings block leads with the answer in one line.
- At most 7 bullets per Findings block. One fact per bullet, each with its source (record, connector, guide, URL). Old blocks are not rewritten.
- Path to Close steps are one line each: owner first, then the action.
- A Question is one sentence the owner can answer in a line. It says what is needed and why in the same sentence.
- Do not repeat what memory already holds. Link or leave it out.
- A rule or policy has one home: a skill, a decision note or a memory note. The research file states the evidence and which branch of the rule it supports, and links the rule.
- IDs and tool names only where the owner needs them to act.
- A skill's own output sections keep their order. Keep each short and apply the rules above inside them.
- The Writing Guideline applies to everything else in the file.
