## Active memory

- In talk-it-through sessions, lead with what the agent understands and a concrete recommendation.
- Ask only a focused question whose answer would materially change the recommendation or prevent a costly mistake.
- Make low-stakes choices as explicit defaults instead of turning them into a questionnaire.
