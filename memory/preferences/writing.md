## Active memory

Goal: the owner can read it once and act. This applies to every agent and every output.

- Plain words. No filler, no stacked hedges ("might possibly perhaps").
- Lead with the answer or the status. Detail follows.
- Cut anything the owner does not need to act. If a sentence changes no decision, delete it.
- One fact per bullet or sentence.
- Expand an acronym the first time it appears.
- IDs, tool names and file paths only where the owner needs them to act.
- Do not repeat what memory or an earlier line already says.
- State what was checked and what was not. Never present a guess as a finding.
- The three complaints behind this guideline: too long, too dense or full of jargon, and no clear next step.
