## Active memory

James's IT workspaces use these Client Memory subjects:

- `halo`: client ID, contracts, ticket habits and sites.
- `365`: Microsoft 365, Entra and Exchange tenant facts.

Subjects are set in each workspace's `memory/schema.json`; these IT-specific subjects are not defaults for other owners.
